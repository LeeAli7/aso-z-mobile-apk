Шапка чата Меню (слева), название сессии приглушённым (центр), + (справа). Прозрачный фон, список под шапкой с отступом top+64. Капсула модели · капсула конфига/хранилища · GlassBackdrop-свечения · стеклянные блюры кнопок.
Панель (верх) Новый чат · Модель (инлайн-раскрытие) · Провайдеры · Агент · Проекты · Настройки · строка лимита. Отдельные bottom-sheet модели, сессий, StorageSheet — заменены панелью.
Панель (низ) Поиск чатов · список сессий (название, счётчик, дата) · переименование/удаление по долгому тапу. Кнопка «＋» fullwidth — обычная «+ Новый чат» сверху панели.
Ввод Плоская капсула: + (вложения) · поле · отправить/стоп. Кнопка микрофона без логики (вернуть, когда будет голосовой ввод) · Glass-обёртка.
Эмодзи/текст Чистые текстовые лейблы, иконки MaterialIcons. «🚀» в онбординге · «＋» fullwidth · текстовые «✕/✓»-кнопки в StorageSheet/Providers.
Пустые состояния Чат: приветствие сверху + 3 чипа · Сессии: «Пока нет чатов» · Поиск: «Ничего не найдено» · Модели: «Нет моделей — добавь провайдера». Пустые листы без подсказки следующего шага.

Навигация: Stack остаётся, добавляется Drawer (рекомендуется @react-navigation/drawer) с единственным пунктом — ChatScreen; Провайдеры / Агент / Проекты / Настройки открываются из панели через navigation.navigate, назад — стрелкой. Логика команд, gateway, slash-команды, cron, runtime — не затрагиваются.
