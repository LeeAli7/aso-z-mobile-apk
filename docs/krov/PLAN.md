# Aso-z · пересборка приложения в стиле «КРОВЬ»

Границы: только мобильное приложение (`~/aso-z-mobile-apk`). Telegram-бот и TMA не трогаем.

## 1. Стиль

| Что | Значение |
|---|---|
| Фон | `#000000` |
| Карточка | `#141416`, вторая ступень `#1C1C1F` |
| Текст | `#FFFFFF`, вторичный `rgba(235,235,245,.45)`, третичный `.28` |
| Кровь | `#FF3B30` — только ошибка, подтверждение, разрушительное действие |
| Главное действие | белая капсула, чёрный текст |
| Второстепенное | голый белый текст |
| Радиусы | карточка/окно 20, капсула 25 |
| Иконки | сетка 24×24, обводка 2.0, вторичные детали 42% тона, часть форм залита |
| Шрифт | MiSans (кириллица), Geist Mono для ID и команд |
| Запрещено | градиенты, свечения, цветные акценты кроме крови, «дашборд из коробок» |

## 2. Структура

Чат — единственный главный экран. Всё остальное за бургером:

```
панель:  Новый чат
         Проекты · Агенты · Коннекторы · Хранилище · Настройки
         поиск
         сессии
```

Внутри раздела — список «отделов», контролы живут внутри своего отдела.
Верх — плавающие стеклянные кнопки `☰` / плашка модели / `+`, полосы-шапки нет.

## 3. Решения по разделам

| Раздел | Решение |
|---|---|
| Чат | переписать на новый каркас, сохранить стрим, вложения, размышления цитатой, tool-вызов карточкой |
| Проекты | `VibeScreen` + `VibeProjectScreen` сводятся в один раздел: проект = папка + чат + файлы + терминал |
| Терминал | шторка снизу внутри проекта, не отдельный экран |
| Агенты | субагенты + память + скиллы + задачи + автозадачи; все экраны реальные, без карточек-пустышек |
| Коннекторы | MCP и webhooks доделать до рабочего состояния, мессенджеры показывать честным статусом |
| Хранилище | **с нуля**; старый `StorageSheet` (1010 строк, недостижим) не используем |
| Настройки | только реальные переключатели; расход токенов — строкой внутри |
| Задачи | Kanban переделывается на движок `core/todo.ts`, дублирующий стор удаляется |
| Расход | реальный учёт токенов из стрима вместо `const STATS = []` |

## 4. Что чинить по аудиту

Полные отчёты: `docs/audit/ui.md`, `docs/audit/core.md`.

1. Переключатели настроек декоративные — подключить `agentConfig`, `security`, `delegation`, `voice`.
2. `/model` в `/help` без обработчика.
3. Cron: интервальные расписания не срабатывают (`nextRunAt` при `lastRunAt=null`), тик живёт в экране чата — вынести в фон.
4. Гейт тулсетов не применяется к промпту — модель видит выключенные инструменты.
5. Два источника правды: `kanban.ts`, `connectors.ts`, `voice.ts`, `display.ts` не импортируются, экраны пишут те же ключи сами.
6. Бэкап выгружает ключи открытым текстом, `crypto.ts` — XOR. Шифровать.
7. `write_file` без проверки traversal, `isBlockedUrl` не вызывается, redact на шести шаблонах.
8. «Агенты»: 4 карточки ведут на одну доску.
9. «Переименовать» проект — no-op, `ToolCard` в чате проекта навсегда `loading`.
10. Синхронизация и web-режим мертвы (`127.0.0.1:8000`, сервера нет) — либо честно выключить, либо поднять.
11. Удаление провайдера/модели без подтверждения.
12. Мёртвый груз: 13 движков в `core`, `Drawer.tsx`, `icons/*`, часть `design-system`.

## 5. Фазы

- **Ф0. Фундамент** — токены КРОВЬ, набор иконок (52 глифа), примитивы (карточка 20, капсула 25, строка отдела).
- **Ф1. Каркас и чат** — навигация «чат + панель», новый `ChatScreen`, композер, сообщения.
- **Ф2. Разделы** — Проекты, Агенты, Коннекторы, Хранилище (с нуля), Настройки.
- **Ф3. Функции и баги** — список из раздела 4, по одному, с проверкой.
- **Ф4. Сборка** — APK через GitHub Actions, проверка на телефоне.

## 6. Критерий готовности

Ни одного декоративного контрола. Каждая кнопка либо делает то, что обещает, либо отсутствует.
